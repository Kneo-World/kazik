Чтобы отобразить свои уникальные PNG картинки для кейсов и брейнротов в проекте, загрузите их в GitHub репозиторий по следующей структуре:

📁 your-repo-name/
├── 📄 index.html
└── 📁 assets/
├── 📁 cases/
├── 🖼️ free_case.png
└── 🖼️ starter_case.png
└── 📁 brainrots/
├── 🖼️ los_trios.png
├── 🖼️ 67.png
├── 🖼️ spinny_hammy.png
